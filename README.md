# 🩺 MediCheck  

AI-powered symptom checker built using Retrieval-Augmented Generation (RAG) to provide reliable, document-grounded health insights with citations and responsible AI outputs.  

---

## ⚙️ Technologies  
- Django  
- React  
- Pinecone (Vector Database)  
- Hugging Face  
- Python  

---

## ✨ Features  

Here’s what you can do with MediCheck:  

- **Symptom Analysis:** Enter symptoms and get AI-generated health insights  
- **RAG Pipeline:** Retrieves relevant medical data before generating responses  
- **Citations:** Provides source-backed answers for reliability  
- **Responsible AI:** Includes disclaimers for safe usage  
- **Frontend UI:** Interactive interface built with React  
- **Vector Search:** Fast retrieval using Pinecone  

---

## 🧠 The Process  

- Built a RAG-based pipeline combining retrieval and generation  
- Integrated Pinecone for efficient vector similarity search  
- Used Hugging Face models for NLP and response generation  
- Developed backend APIs using Django  
- Created a responsive frontend with React  
- Focused on delivering accurate, explainable AI outputs

## 🚀 How to Run  

```bash
# Clone the repository
git clone https://github.com/your-username/MediCheck.git

# Navigate to project folder
cd MediCheck
```

### Backend (Django)
```bash
cd backend
pip install -r requirements.txt
python manage.py runserver
```

### Frontend (React)
```bash
cd frontend
npm install
npm start
```
